STI 2026-2027 / TP 01 — Positionnement

1Le flux normal : position: static

Page de démonstration
  • Valeur par défaut de tous les éléments.
  • Les blocs s'empilent de haut en bas, dans l'ordre du code HTML.
  • top, right, bottom, left n'ont aucun effet sur un élément static.

2relative : décalé, mais il garde sa place

Page de démonstration
  • Le décalage se mesure depuis la place d'origine.
  • L'espace d'origine reste réservé (pointillés) : les autres éléments ne bougent pas.
  • relative seul ne déplace rien : il faut top / left…
Dans le TP 01 : le cadre #carousel-container.

3absolute : hors du flux, placé par rapport à un repère

Page de démonstration
  • Il sort du flux : les éléments suivants remontent.
  • Repère : l'ancêtre positionné le plus proche (position autre que static), sinon la page.
Dans le TP 01 : la légende, « Précédent » et « Suivant ».

4fixed : placé par rapport à la fenêtre

Fenêtre du navigateur (la page défile)
  • Repère : la fenêtre du navigateur.
  • Il reste en place quand on fait défiler la page.
  • Il sort du flux, comme absolute : il ne prend plus de place.
Dans le TP 01 : le pied de page.
